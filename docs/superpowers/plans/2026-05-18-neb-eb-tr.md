# NEB EB/TR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the computed NEB path less prone to unphysical rigid rotation and lateral image drift for SN2 animations.

**Architecture:** Expose ASE NEB `method` and `remove_rotation_and_translation` through the TOML schema, default to `method="eb"` and `remove_rotation_and_translation=true`, and record the effective values in metadata. Keep the rendering pipeline unchanged so improvements come from the computed path.

**Tech Stack:** Python dataclasses, TOML validation, ASE NEB, pytest.
